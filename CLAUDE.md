# jacobcheatley.com

Personal website for fun projects and learning. See `README.md` for the tech stack.

## Agent skills

### Issue tracker

Issues are tracked as GitHub Issues on `jacobcheatley/jacobcheatley-com` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Git workflow

Branches are `type/ticket#-short-name` (throwaway `prototype`/`research` may drop the ticket); PRs squash-merge into `main`. See `docs/agents/git-workflow.md`.

### Domain docs

Single-context: `CONTEXT.md` (glossary) and `docs/adr/` at the repo root. Layout and conventions: see `docs/agents/domain.md`.
