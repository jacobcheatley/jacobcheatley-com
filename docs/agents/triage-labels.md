# Triage labels

This repo uses the five canonical triage roles as label strings, verbatim. When a skill names a role, apply that exact label.

- `needs-triage` — not yet evaluated
- `needs-info` — underspecified; needs more detail from the owner before it can proceed
- `ready-for-agent` — fully specified, ready for an AFK agent
- `ready-for-human` — needs the owner to implement it
- `wontfix` — will not be actioned

Labels are created on GitHub the first time they are applied.
